# Технические задания по рефакторингу DIP в onPHP

Данная директория содержит детализированные технические задания (ТЗ) для каждого этапа рефакторинга, направленного на устранение нарушений принципа Dependency Inversion в проекте onPHP.

## Общий план

Рефакторинг разбит на 9 этапов (0–8), каждый из которых фокусируется на определённой группе нарушений. Общий план описан в документе [План исправления DIP](../roadmap/План_исправления_DIP.md).

## Структура каждого ТЗ

Каждое техническое задание содержит следующие разделы:

1. **Общая информация** – номер, название, сроки, трудозатраты, приоритет.
2. **Цель этапа** – краткое описание того, что должно быть достигнуто.
3. **Задачи** – детальный перечень действий с описанием и результатами.
4. **Критерии успеха** – чек-лист для проверки завершения этапа.
5. **Риски и митигация** – потенциальные проблемы и способы их минимизации.
6. **Следующий этап** – ссылка на следующий этап.

## Использование

Эти ТЗ предназначены для:

- **Планирования работ** – оценка сроков и ресурсов.
- **Распределения задач** между разработчиками.
- **Контроля прогресса** – сверка с критериями успеха.
- **Документирования процесса** рефакторинга.

## Как вносить изменения

Если в процессе реализации потребуется скорректировать ТЗ (например, из-за новых обстоятельств), следует:

1. Внести правки в соответствующий файл ТЗ.
2. Обновить таблицу выше (если изменились сроки/приоритеты).
3. Уведомить команду о изменениях.
